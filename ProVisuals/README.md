# ProVisuals

A clean Fabric client-side core mod for Minecraft Java 26.2.

## Project goals

- Modern, minimalistic interface
- Right Shift overlay over the live Minecraft screen
- Free-position workspace with corner resizing
- Independent HUD visibility and interaction per module
- Theme customization: Round / Soft / Sharp corners and accent colors
- Saved layouts and GUI-scale-aware positioning
- Extension API for future ProVisuals modules

## Development

- Minecraft: 26.2
- Mod loader: Fabric
- Java: 25
- Gradle: 9.8.0
- Fabric Loader: 0.20.1
- Fabric API: 0.161.0+26.2

This is a fresh implementation. No previous SurvivalClient source is reused.
